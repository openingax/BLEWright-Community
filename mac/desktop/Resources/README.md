# BLEWright 图标素材

AppIcon.png 为内置 imagegen 工具生成的透明底原图。AppIcon.icns 是同一原图以 sips 缩放到标准 iconset 尺寸、由 iconutil 转换的 macOS 资源，供 Dock、Finder、应用及警告弹窗使用。

生成提示词：

> Use case: logo-brand. Create a polished macOS app icon for BLEWright, a USB Bluetooth developer workstation. Square 1024x1024 composition, actual transparent exterior. Single large rounded square dark midnight navy enamel tile, generous clean inset. Central sculptural mint turquoise radio/Bluetooth-inspired angular B monogram, with two subtle concentric signal arcs to the upper right, machined soft bevels, restrained luminous edge, modern premium utility app. Strong simple silhouette readable at 32 pixels, balanced centered composition. No text, letters spelling words, labels, watermark, mockup, extra objects, or white background. Tile occupies about 86% of canvas, soft minimal shadow. Deliver only the finished icon.

界面中的电路板插画在 Design.swift 中由 AppKit 绘制，可无损缩放。功能图标使用 SF Symbols。
